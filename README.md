# myTunes — Music & Entertainment Landing Page

A sleek, modern landing page clone inspired by Apple's iTunes, built using **HTML5**, **CSS3**, and **Font Awesome**. Designed to showcase music streaming, movies & TV collections, entertainment highlights, and gift cards with smooth section navigation.

---

## Live Demo

- **GitHub Pages:** `https://pawan-54.github.io/<your-repo-name>/`  
  *(Replace `<your-repo-name>` with the name of your GitHub repository)*

---

## Features

- **Sticky Navigation Bar:** Smooth-scrolling links to **Overview**, **Music**, **Video**, and **Gift Cards** sections.
- **Full-Screen Hero Section:** Bold typography and full-bleed background imagery introducing the myTunes platform.
- **Music Showcase:** Highlights 45 million+ ad-free tracks, offline listening, and overlapping device mockups (`iPad` & `iPhone`).
- **Movies & TV Section:** Clean showcase of 4K HDR movies and TV shows with desktop preview imagery (`Mac`).
- **Entertainment Banner:** Full-width visual banner section with centered typography.
- **Gift Cards Section:** Two-column layout featuring a gift card preview and redemption call-to-action.
- **Multi-Column Footer:** Organized links across *Shop & Learn*, *Orange Store*, *Education & Business*, and *About Orange*.

---

## Tech Stack

- **HTML5** — Semantic page structure (`header`, `nav`, `main`, `section`, `footer`)
- **CSS3** — CSS Custom Properties (`:root` variables), Flexbox, CSS Grid, sticky positioning, and smooth scrolling
- **Google Fonts** — [Roboto](https://fonts.google.com/specimen/Roboto)
- **Font Awesome** — Icons (`fa-music`)
